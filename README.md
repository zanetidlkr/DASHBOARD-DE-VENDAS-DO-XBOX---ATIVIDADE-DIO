# 🎮 Dashboard de Vendas do Xbox

Dashboard interativo criado no Excel para analisar as vendas de assinaturas do Xbox, transformando dados brutos em informações claras para apoiar decisões de negócio.

## 🎯 Objetivo

Construir um dashboard no Excel que responda perguntas estratégicas sobre as vendas do Xbox, aplicando tabelas dinâmicas e boas práticas de design, e documentar todo o processo de forma clara no GitHub.

## ⚙️ Funcionalidades

- Visão geral das vendas em um único painel
- Tabelas dinâmicas para resumir e cruzar os dados
- Gráficos para facilitar a leitura dos resultados
- Design organizado, com identidade visual consistente
- Respostas a perguntas de negócio baseadas nos dados

## 🧠 Como funciona

1. Os dados de vendas ficam organizados em uma base de dados na planilha.
2. Os **gráficos** são criados a partir das tabelas dinâmicas.
3. O **dashboard** reúne os principais indicadores e gráficos em uma única tela.
4. A partir da análise, são respondidas perguntas estratégicas de negócio.

## 📚 Conceitos aplicados

- Tabelas dinâmicas
- Criação de gráficos
- Design de dashboard no Excel
- Organização e estética de planilhas
- Análise de dados voltada a decisões de negócio

## ▶️ Como usar

1. Baixe o arquivo `.xlsx` deste repositório.
2. Abra no Microsoft Excel.
3. Acesse a aba do dashboard para ver os indicadores.
4. Explore as tabelas dinâmicas para aprofundar a análise.

## 🛠️ Tecnologias

- Microsoft Excel (tabelas dinâmicas, gráficos e formatação)
- GitHub (documentação e versionamento)

## 💡 Aprendizados

- Desenvolver o design de um dashboard no Excel

- Documentar um projeto técnico de forma clara e estruturada
